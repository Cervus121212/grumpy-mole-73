A program that writes one original roast line (101 characters) about a smart fridge that texts its owner about being out of milk while the owner stands in front of it holding the milk.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
